# CarInOut

钥匙车内外识别项目。第一步：把采集到的各锚点（SLAVE）CSV 按点位整合成数据集。

## 数据集构建工具

![界面示意](docs/screenshot.png)

### 安装与启动

```bash
pip install -r requirements.txt
python main.py
```

### 输入

一个文件夹，内含若干 CSV，文件名格式为 `场景_点位_锚点*.csv`，例如 `中排座椅_53_SLAVE2.csv`：

| 部分 | 示例 | 说明 |
| --- | --- | --- |
| 场景 | 中排座椅 | 可包含下划线 |
| 点位 | 53 | 不含 `_`、`-`、空格 |
| 锚点 | SLAVE2 | `SLAVE` + 数字，不区分大小写，其后可带任意后缀 |

分隔符可以是 `_`、`-` 或空格。文件名规则是一个正则表达式，可在界面中修改，
只需保留命名分组 `scene`、`point`、`anchor`。无法识别的文件会列在日志中。

### 使用步骤

1. **选择输入文件夹** → 自动解析，左侧按 场景 / 点位 列出数据；缺少某些 SLAVE 的点位以橙色标出。
2. **SLAVE → 锚点映射**：右侧为每个 SLAVE 在下拉列表中选择车模上的锚点。
   - 车模中央为俯视图（车头朝上）：车外 8 个锚点（四角 + 十字），车内 2 个锚点。
   - 默认名称：`FL` 左前角、`F` 车头正中、`FR` 右前角、`R` 右侧正中、`RR` 右后角、
     `B` 车尾正中、`RL` 左后角、`L` 左侧正中、`IF` 车内前部、`IR` 车内后部。
   - **双击车模上的锚点可重命名**，名称即合并后列名的后缀。
   - 两个 SLAVE 选了同一锚点会标红，必须修正后才能导出；未分配的 SLAVE 在导出时忽略。
   - 映射、锚点名称、文件名规则保存在 `config.json`，下次启动自动恢复。
3. **预览点位**：在左侧点击某个点位，车模上显示每个锚点 `errcode=0` 的有效行数 / 原始行数。
4. **合并导出**：选择输出文件夹（默认 `输入文件夹/merged`），点击“开始合并导出”。

### 输出

- 每个 (场景, 点位) 一个文件：`场景_点位.csv`，例如 `中排座椅_53.csv`。
- 只保留 `errcode` 为 0 的行（列名不区分大小写；`0`、`0.0`、带空格均视为 0）。
- 列名与原文件一致，加上 `_锚点名` 后缀，锚点按车模顺序排列：
  `timestamp_FL, rssi_FL, …, errcode_FL, timestamp_F, …`。
- 各锚点按行号横向对齐，可选：
  - **按最短锚点截断**（默认）：每一行都包含所有锚点的数据；
  - **保留全部行**：较短的锚点补空。
- 可勾选“只导出已映射锚点齐全的点位”，否则缺失锚点的点位只包含现有锚点的列。
- 同一点位同一 SLAVE 有多个文件时，按文件名顺序纵向拼接后再合并。
- 数值按原始文本写出，不改变格式；输入支持 UTF-8 / GBK 编码。
- `_summary.csv`：每个点位的输出行数、状态以及各锚点的有效行 / 原始行数。
